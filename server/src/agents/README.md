# AI Agents Layer

This directory will contain the reasoning and LLM-driven agents responsible for:
- `jobAnalyzerAgent.js`: Parses job descriptions, extracts core tech requirements, culture fit, and red flags.
- `resumeMatcherAgent.js`: Evaluates candidate resume vs job description and suggests tailored bullet points.
- `formFillerAgent.js`: Interprets dynamic application form questions and synthesizes accurate, authentic answers based on the user's verified profile.
