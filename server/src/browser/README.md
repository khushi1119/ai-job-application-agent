# Browser Automation Layer (Browserbase)

This directory is designated for Browserbase cloud browser automation:
- `browserbaseClient.js`: Connection manager, session pooling, and context configuration.
- `domHelpers.js`: Safe element discovery, human-like typing, click handlers, and CAPTCHA interception guards.
- `jobScraper.js`: Navigation to job board URLs and extraction of application forms.
- `formSubmitter.js`: Multi-step form completion and submission workflow with human-in-the-loop confirmation.
